Estou desenvolvendo um RPG de fantasia em Python, projeto que vem sendo utilizado para colocar em prática conceitos de programação e desenvolvimento de software em um projeto maior e contínuo.
Até o momento, estou trabalhando com:
- 🐍 Python e POO — classes, objetos, herança, encapsulamento e organização de responsabilidades;
- ⚔️ Sistema de combate — ataques, atributos, níveis, dano, crítico, defesa e parry;
- 🎨 Manipulação de imagens e animações com Pygame;
- 🎵 Sistema de áudio e transições para as cenas;
- 💾 Persistência de dados utilizando JSON;
- 🗂️ Organização modular do projeto, separando sistemas, entidades, cenas e utilitários;
- ⌨️ Interação via teclado e sistemas de entrada do jogador.
A ideia é utilizar o desenvolvimento do jogo não apenas como um projeto de entretenimento, mas também como uma forma de aprofundar meus conhecimentos em Python, arquitetura de software e desenvolvimento de aplicações.
🚀 Próximos passos
Ainda pretendo evoluir bastante o projeto, adicionando:
- novos inimigos e sistemas de batalha;
- progressão de personagem;
- novas áreas e chefes;
- sistema de habilidades;
- mais cenas e elementos narrativos;
- melhorias na arquitetura do projeto;
- otimização e refinamento da experiência de jogo.
É um projeto em desenvolvimento, então muita coisa ainda está sendo experimentada e modificada, mas justamente esse processo tem sido uma das partes mais interessantes: transformar conceitos de programação em um sistema funcional e cada vez maior.
